# State codes

Use these codes in the `state` field of a billing or shipping address when the `country` is `US`.

{% hint style="info" %}
For card payments in the United States, a correct `state` materially improves **AVS** match rates. See [Address Verification Service](../guides/address-verification-service.md).
{% endhint %}
